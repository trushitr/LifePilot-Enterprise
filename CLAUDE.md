# Claude Code guidance

This is a local-first ASP.NET Core + React app. Run `dotnet test backend/LifePilot.Tests/LifePilot.Tests.csproj` and `npm run build` inside `frontend` after edits. Use fake data only. Do not commit credentials or databases. Do not retry non-idempotent database writes automatically. Make focused, verifiable commits and document trade-offs.
